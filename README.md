# 📄 منشئ السيرة الذاتية · CV Builder

أداة تعمل بالكامل داخل المتصفح تحوّل بياناتك إلى سيرة ذاتية احترافية بمعاينة حية، وتنزّلها كملف **PDF بتنسيق ATS**، وتستطيع (اختيارياً) تخصيص سيرتك لوظيفة معيّنة بالذكاء الاصطناعي.

> **English summary:** A zero-backend, single-file (`index.html`) resume builder in Arabic and English. Live A4 preview, 4 templates, rule-based ATS checker, ATS-friendly PDF download, multiple saved resumes, and an optional AI job-tailoring feature (bring your own Anthropic API key). Built with React 18 (UMD via CDN) and jsPDF. No build step, deploys straight to GitHub Pages.

🔗 **الموقع المباشر:** https://nawraswadi.github.io/cv-builder/

📦 **المستودع:** https://github.com/NawrasWadi/cv-builder

## ✨ المزايا

### النموذج
- 7 خطوات مع شريط تقدم: معلومات شخصية ← ملخص ← خبرات ← تعليم ← مهارات ← مشاريع ← لغات.
- الخبرات والتعليم والمشاريع قابلة للإضافة والحذف وإعادة الترتيب (أعلى/أسفل).
- صورة شخصية اختيارية، تُضغط تلقائياً (حد أقصى 320px، JPEG) وتُحفظ كـ Data URL.
- تحقق من البريد والهاتف والحقول المطلوبة برسائل غير مزعجة (تظهر بعد مغادرة الحقل).
- اقتراح أفعال قوية (عربي/إنجليزي) تحت وصف كل خبرة، بضغطة واحدة.

### المعاينة والقوالب
- معاينة بحجم A4 تتحدث أثناء الكتابة، وتتصغّر تلقائياً لتناسب عرض الشاشة.
- على الموبايل: تبويبان «تعديل / معاينة».
- 4 قوالب مختلفة فعلاً بالتخطيط: **كلاسيكي**، **عصري** (عمودان)، **بسيط**، **إبداعي**.
- 6 ألوان تمييز وثلاثة خطوط (Cairo, Tajawal, Inter).
- لغة السيرة مستقلة عن لغة الواجهة (واجهة عربية وسيرة إنجليزية، والعكس).

### التصدير
- **تنزيل PDF** مباشر على الجهاز (بدون نافذة طباعة) بتنسيق ATS، انظر القسم التالي.
- **نسخ كنص عادي** للصقه في نماذج التوظيف.
- **نسخ احتياطي JSON**: نسخ، تنزيل ملف، أو استيراد من نص/ملف.

### مدقق ATS (بقواعد برمجية، بدون AI)
درجة من 100 مع تفصيل واقتراحات قابلة للتنفيذ:

| القاعدة | النقاط | الشرط |
|---|---|---|
| اكتمال البيانات | 20 | الاسم، المسمى، البريد، الهاتف، المدينة، الرابط (بالتناسب) |
| طول الملخص | 15 | 200–600 حرف (8 نقاط إن كان 80–199) |
| الخبرات | 15 | خبرة واحدة على الأقل مع وصف (6 بدون وصف) |
| أرقام في الإنجازات | 15 | نسبة الأسطر التي تحتوي رقماً |
| أفعال قوية | 15 | نسبة الأسطر التي تبدأ بفعل من القائمة |
| عدد المهارات | 10 | من 6 إلى 15 (5 نقاط خارج هذا النطاق) |
| التعليم | 5 | مؤهل واحد على الأقل |
| حجم السيرة | 5 | صفحتان كحد أقصى (تقدير من المعاينة) |

### تخصيص السيرة لوظيفة (ذكاء اصطناعي، اختياري)
1. اضغط **«✦ تخصيص لوظيفة»**.
2. الصق وصف الوظيفة. وسيرتك الأصلية إما تُترك فارغة (فتُستخدم السيرة المفتوحة) أو تلصق نصها في الحقل الاختياري.
3. تُنشأ **نسخة جديدة** في قائمة سيرك، وسيرتك الأصلية لا تتغير، مع قائمة بما تغيّر.

الـ prompt مصمم لـ: عدم اختراع أي خبرة أو شركة أو مهارة أو رقم، وإبقاء بيانات التواصل كما هي، وإعادة كتابة الملخص، وترتيب الخبرات والمهارات حسب الصلة، وتجاهل أي تعليمات مدسوسة داخل نص الوظيفة أو السيرة.

### أخرى
- عدة سير محفوظة (إنشاء، نسخ، إعادة تسمية، حذف).
- وضع داكن/فاتح يحترم `prefers-color-scheme`، مع زر تبديل.
- واجهة عربية/إنجليزية مع RTL/LTR تلقائي.
- إتاحة: `aria-label`، تركيز لوحة المفاتيح، إغلاق النوافذ بـ `Esc`.

## 📑 PDF بتنسيق ATS

الملف المنزّل **يختلف عن شكل المعاينة** عمداً، لأن أنظمة ATS تقرأ النص الخام وتتعثر بالتصاميم:

- عمود واحد، بدون جداول أو أعمدة أو صور أو ألوان.
- نص حقيقي قابل للتحديد والنسخ (ليس صورة).
- ترتيب ثابت وأسماء أقسام قياسية: ملخص ← خبرات ← تعليم ← مهارات ← مشاريع ← لغات.
- المسمى والشركة في سطر، والفترة تحته، والإنجازات بنقاط `•`.
- A4 بهوامش 18mm، وتنتقل الأقسام بين الصفحات تلقائياً.
- الصورة الشخصية **لا تدخل** الملف.

> القالب المختار والخط واللون تؤثر على **المعاينة فقط**. الملف المنزّل يستخدم خط DejaVu Sans المضمّن.

## 🚀 التشغيل والنشر

### محلياً
افتح `index.html` في المتصفح مباشرة، أو شغّل خادماً بسيطاً:
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
> يحتاج اتصالاً بالإنترنت لتحميل المكتبات من الـ CDN.

### GitHub Pages
1. أنشئ مستودعاً عاماً وارفع `index.html` (والـ `README.md`).
2. **Settings ← Pages ← Deploy from a branch** ← الفرع `main` والمجلد `/ (root)` ← **Save**.
3. بعد دقيقة يظهر الرابط: `https://nawraswadi.github.io/cv-builder/`

## 🔐 الخصوصية والأمان

- **لا يوجد خادم.** بياناتك لا تغادر متصفحك إلا في حالة واحدة: عند استخدام ميزة الـ AI (انظر أدناه).
- التخزين في `localStorage` ضمن `try/catch` مع تجاهل آمن إذا كان التخزين محجوباً، والبيانات التالفة تُعاد تنظيفها عند التحميل ولا تكسر التطبيق.
- المفاتيح المستخدمة: `cvb:v1` (السير والإعدادات) و`cvb:key` (مفتاح API).
- **لا يوجد أي مفتاح API في الكود.** المستخدم يلصق مفتاحه بنفسه، ويُحفظ في متصفحه فقط، وفيه زر حذف.
- المفتاح **لا يُضمَّن** في النسخ الاحتياطي JSON.

### ⚠️ تنبيه حول مفتاح API في المتصفح
أي مفتاح يُستخدم من المتصفح مباشرة يكون مكشوفاً لأي سكربت يعمل في الصفحة. لذلك:
- استخدم مفتاحاً **بحد إنفاق منخفض** مخصصاً لهذا الغرض.
- لا تضع مفتاحك داخل الملف أبداً ولا ترفعه إلى GitHub.
- المسار يستخدم ترويسة Anthropic المخصصة للطلبات من المتصفح (`anthropic-dangerous-direct-browser-access`)، وتسمية الترويسة نفسها تذكير بهذه المخاطرة.

### الذكاء الاصطناعي: سلوك الميزة حسب مكان التشغيل
| المكان | السلوك |
|---|---|
| داخل claude.ai (كـ Artifact) | يعمل بدون مفتاح عبر Claude، مع طلب موافقة عند أول استخدام |
| GitHub Pages / محلياً | يظهر حقل مفتاح Anthropic API، والطلب يذهب مباشرة إلى `api.anthropic.com` |

معالجة الأخطاء: مفتاح خاطئ، حد الاستخدام، انقطاع الاتصال، رد غير مفهوم، رفض الموافقة، كلها برسائل ودّية، والتطبيق يبقى يعمل كاملاً بدون AI.

## 🗂️ هيكل الكود

كل شيء في `index.html`، بالترتيب:

```
<head>        CSS (متغيرات الألوان للفاتح/الداكن، تنسيق الواجهة، تنسيق السيرة)
<script>      window.CVF  ← الخطوط المضمّنة base64 (Regular / Bold)
<script>      CDN: jsPDF, React, ReactDOM, Babel
<script type="text/babel">
  T            كائن الترجمة (ar / en) لكل النصوص
  VERBS/ACC/…  الأفعال القوية، ألوان التمييز، الخطوط، القوالب
  Ic           أيقونات SVG مضمّنة
  blank/norm   نموذج البيانات + تنظيف أي بيانات تالفة
  load/save    التخزين المحلي الآمن
  ats()        قواعد مدقق ATS
  Field/List/Verbs/compress   مكونات النموذج وضغط الصورة
  Resume       معاينة السيرة (4 قوالب)
  plain()      التحويل إلى نص عادي
  buildPDF()   مولّد PDF بتنسيق ATS (jsPDF)
  buildPrompt/callAI   طبقة الذكاء الاصطناعي
  Modal / App  النوافذ والتطبيق الرئيسي
```

نموذج البيانات لكل سيرة:
```js
{ id, name, rl: "ar"|"en", tpl, ac, font, photo,
  p: { name, title, email, phone, city, link },
  summary, exp: [{role, co, period, desc}], edu: [{deg, school, period}],
  skills: "a, b, c", proj: [{name, link, desc}], langs: "a, b" }
```

## 🛠️ التخصيص

| تريد أن | عدّل |
|---|---|
| تغيّر ألوان التمييز | المصفوفة `ACC` |
| تضيف خطاً للمعاينة | `FONTS` + رابط Google Fonts في `<head>` |
| تضيف لغة | أضف مفتاحاً جديداً في `T` و`VERBS`، وعدّل التبديل في `App` |
| تغيّر ألوان الواجهة | متغيرات CSS في `:root` و`[data-theme="dark"]` |
| تعدّل قواعد ATS | الدالة `ats()` |
| تعدّل أفعال الاقتراح والتصحيح | الكائن `VERBS` |
| تعدّل الـ prompt | الدالة `buildPrompt()` |
| تغيّر موديل Claude | قيمة `model` داخل `callAI()` |
| تعدّل تنسيق الـ PDF | الدالة `buildPDF()` (الهوامش `M`، أحجام الخطوط) |

## ⚠️ قيود معروفة

1. **PDF بالعربية:** يعتمد على دعم jsPDF للعربية مع خط DejaVu. قد تظهر مشاكل في ربط الحروف أو اتجاه النصوص المختلطة (عربي + إنجليزي + أرقام). جرّب سيرتك قبل التقديم.
2. **قراءة ATS للعربية:** حتى لو ظهر الملف سليماً، استخراج النص العربي من PDF أضعف عموماً في أنظمة ATS منه في الإنجليزية، فاستخدم نسخة إنجليزية للوظائف التي تمر عبر ATS.
3. **الخط:** ملف الـ PDF يستخدم DejaVu وليس خط المعاينة.
4. **عدد الصفحات في المدقق:** تقدير من حجم المعاينة على الشاشة، وليس من ملف الـ PDF الفعلي.
5. **الـ AI على GitHub Pages:** يتطلب مفتاح Anthropic API، ولا يوجد تحقق مسبق من المفتاح قبل الإرسال.
6. **أول تحميل:** Babel يترجم الكود داخل المتصفح، فقد يتأخر الفتح الأول لحظات. هذا مقبول لمشروع معرض أعمال، وليس لإنتاج واسع النطاق.
7. **صفحات المعاينة:** لا تُرسم فواصل الصفحات على الشاشة، وتظهر فقط في ملف الـ PDF.
